# Albion Bot Lab

Bot Android de test (vidéo YouTube). Il voit l'écran (MediaProjection), simule les appuis
(service d'accessibilité) et journalise chaque décision. Inspiré de a-Fig/Automated-Game-Bot (Python, PC),
réécrit pour mobile.

- Vision : barres de vie ennemies par couleur calibrée, vie du joueur, sorts prêts (luminosité).
- Cerveau : survie (soin/fuite) > combat (ciblage + rotation de sorts) > récolte > exploration.
- APK : Releases, tag `bot-albion-vN`.
