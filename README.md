# Brèche Écarlate (branche APK)

Jeu mobile 3D (Three.js + assets KayKit/Kenney/Quaternius CC0) : place publique, marchand, portail écarlate, 3 armes T1–T8, donjon à 4 boss.

- `www/` : le jeu HTML5.
- `android/` : coque Android (WebView), construite par `.github/workflows/apk.yml` à chaque push sur cette branche.
- L'APK est publié dans les Releases (`breche-ecarlate-v1.N`).
